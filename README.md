# POISON KID — LOVELESS

Landing de pre-save y sorteo para el preview listening de LOVELESS.

## Incluye

- Flujo de pre-save y registro.
- Base de participantes en Neon Postgres.
- Panel privado en `/admin`.
- Exportación CSV.
- Sorteo de hasta 70 invitaciones.

## Variables de Vercel

- `DATABASE_URL`
- `ADMIN_PASSWORD`
- `ADMIN_SESSION_SECRET`

No publiques valores reales en GitHub. Configúralos en Vercel → Settings → Environment Variables.
